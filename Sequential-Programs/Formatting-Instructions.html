Bases 10, 8, and 16

Base 10 is what we commonly use for numbers.  We like to group things into multiples of 10.  Computers store data in bits, which are base 2 (bin, short for binary), either on or off.  They store data in multiples of 2.  While we store 12 as 1-ten and 2-ones, computers store 12 as 1-eight and 1-four (e.g., 1100).  Computers often store data in base 8 (oct, short for octal) using digits 0-7, and base 16 (hex, short for hexadecimal) using digits 0-9 and A-F, as well.  For dec 12, oct is 1-eight and 4-ones (e.g., 14), and hex is 12-ones (e.g., C).  What gets output by the following?

print(10)
print(oct(10))
print(hex(10))

Format Output

Often we want to format data when we display it, so it looks nice.  For example, we may want to line things up in columns or only output two decimal places when displaying money.  Consider the following statements which include formatting using f-strings to print the value stored in x.

x = 7

print(f"{x:>5}") # right-aligned, 5 spaces, default space fill character
print(f"{x:>05}") # right-aligned, 5 spaces, '0' fill character
print(f"{x:<05}") # left-aligned, 5 spaces, '0' fill character
Flag FORMCols (5 pts)

Put the output of each line above together, separated by pipes to build the flag.  For example, if the answers were a, b, c, then enter a|b|c to get the flag.


Image you want to print the data below, which is comprised of two columns.  The first column is 10 characters wide, and the second column is 5 characters wide.  Elements in the first column are right justified, and elements in the second column are left justified.

apple: 27
banana: 18
pear: 22


This can be accomplished with the code below.

print(f"{'apple:':gb} {27:gb}")
print(f"{'banana:':gb} {18:gb}")
print(f"{'banana:':gb} {18:gb}")
