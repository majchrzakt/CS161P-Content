Operators

An operator is a symbol which tells the computer to perform an action on one or more values (aka operands).  Watch this short video2:30 discussing three interesting Python operators.

In Python, which operator is used for division?

answer /

Which operator is used for floor division?

answer //

Which operator is used for modulus (i.e., 5 mod 3 is 2)?

answer %

Which operator is used for multiplication?

answer *

Which operator is used for combined addition and assignment?

answer +=

x += 5 is the same as x = x + 5, which adds 5 to x

Which operator is used for exponents (i.e., raising to a power)?

answer **

Booleans

In addition to integers (e.g., -2, 9, etc.) and real numbers (e.g., 2.7), Python can store booleans (e.g., True, False) values.  As we saw with numbers, it can't catenate a boolean value to a string directly and display it.  The code below WON'T work.

x = True
print("x is " + x) # WON'T work
Flag MTHBoolErr (5 pts)

What compile time error message does the code above generate?  The flag is under the green box.

Flag MTHBoolFix (5 pts)

How can you fix the code above, so it will work?  The flag is under the green box.

x = True
print("x is " + gb(x))
