Why Code Tracing?

Code tracing is useful for understanding how computers execute code and store values in variables.  In particular, it demonstrates the following.

  • Code runs one line at a time
  • Variables have specific values at specific moments

It also can be helpful when trying to debug a program, especially one with a logical error (i.e., no syntax errors and producing results, but results that are NOT correct).

Choose Tab/Partner

Classroom

Students who are able to come to class, can choose a partner during class with whom to complete this task.  Open the Google sheet (see link below).  Choose a tab from those along the bottom of the Google sheet for a sheet which doesn't already have student names at the top, and enter your names.

Online

Students can complete this task online with a partner, either synchronously or asynchronously.  You may use this Discord server to communicate, if you like.  Please set your nickname to the actual (nick)name you're using in this class.  Unrecognized names will be removed.

Synchronous

Identify someone with whom you can schedule a meeting time, and complete the task together.  You may already know someone in the class with whom you can meet.  Alternatively, you could look through the results from the Student Profile Survey (under Course Resources on the course home page) to find another online student who likes to coordinate synchronously and plans to work on this class at the same time you do.  Send them an email to see if they'd like to meet and work on this with you. 

When you meet, open the Google sheet (see link below).  Choose a tab from those along the bottom of the Google sheet for a sheet which doesn't already have student names at the top, and enter your names. 

Asynchronous

If you wish to work asynchronously, look through the tabs along the bottom of the Google sheet (see below) for a tab where the first half has already been completed by another asynchronous student, add your name as Student 2, and finish completing the sheet (see procedure below).  If you can't find a tab which already is half complete, look for a tab which hasn't been started yet, and doesn't already have any student names at the top.  Add your name as Student 1, and complete the first half of the sheet (see procedure below).

Procedure

You'll trace code with your partner using this Google sheet. 

After choosing a tab/partner based on the instructions above, please complete the following steps.

  1. Student 1 -- Fill in the trace table grid with the known values for each variable, line by line, up until where it says to switch students.  If you're working synchronously, the other student should read the line you're on first, then you should explain what you're entering into the table and why.
  2. Student 2 -- Fill in the trace table grid with the known values for each variable, line by line, from the switch student line down to the bottom of the grid.  If you're working synchronously, the other student should read the line you're on first, then you should explain what you're entering in the table and why.
  3. Student 1 and Student 2 -- After completing the Trace Table grid, add your observations to the bottom of the sheet.  If you're working asynchronously, return to the sheet after a peer has completed their portion, verify their entries in the Trace Table are correct, and make your overall observations about the experience.  If no one else has completed the bottom portion by the day this is due, make your observations based only on the top portion you completed.
