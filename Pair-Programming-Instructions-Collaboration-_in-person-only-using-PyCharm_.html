Pair Programming -- Collaboration (in person only using PyCharm)

Why Pair Programming?

It has been used successfully by companies like Facebook, Stripe, Airbnb, Spotify, and Google for tasks such as onboarding and critical systems development.  Advantages include the following.

  • Better Code Quality and Consistency: Real-time reviews reduce bugs and maintain uniform standards.
  • Collaboration and Team Cohesion: Encourages communication, trust, and knowledge sharing.
  • Faster Problem-Solving: Two minds tackle challenges efficiently.
  • Accelerated Learning and Onboarding: Boosts skill development for juniors and simplifies training.
  • Employee Growth and Engagement: Provides mentorship and fosters confidence.

Rules

  • Respect each other’s ideas.
  • Clearly communicate your thought process.
  • Encourage your partner and maintain a supportive attitude.

Set Up (5-10 minutes)

Choose a partner.  Decide who will drive first and who will navigate.

  • Driver: writes code to solve the prompt
  • Navigator: observes and provides feedback

Set up the environment.

  1. The Driver starts PyCharm, clicks the Code with Me icon in the top right corner, selects Edit, and clicks the Start Session button.  After the session starts, the Driver clicks Copy Link and sends it to the Navigator via email, Zoom chat, etc.
  2. The Navigator clicks the link sent by the Driver and specifies a name.
  3. The Driver allows the specified Navigator access to the code.

Prompt 1 (15-20 minutes)

If you have 3 participants in your group, read the instructions for Prompt 3 below first.

Prompt: Write a program that asks the user for the current temperature in Celsius and converts it to Fahrenheit.  Then, based on the temperature, display one of these messages.

  • If it is below 50o F, display "It's cold. Wear a jacket!"
  • If it is between 50o F and 80o F, display "The weather is pleasant."
  • If it is above 80o F, display "It's hot. Stay hydrated!"

Prompt 2 (15-20 minutes)

Switch roles between who is the driver and who is the navigator.

Prompt: Write a program that asks the user for the total shopping amount in dollars. Based on the amount, calculate and display the discount they receive:

  • If the amount is less than $50, no discount is applied.
  • If the amount is between $50 and $100, apply a 10% discount.
  • If the amount is above $100, apply a 20% discount.

Also, display the final amount after applying the discount.

Prompt 3 (10-13 minutes)

Use this prompt if you have 3 participants in your group.  Try to complete each prompt in 10-13 minutes.  Be sure each person has a turn being the Driver.  The other two participants will both be Navigators.  Start with Prompt 1 above.

Prompt: Write a program that asks the user for the number of kilowatt-hours (kWh) they used this month. Based on the usage, calculate the bill:

  • For usage <= 100 kWh, charge $0.10 per kWh.
  • For usage between 100 and 500 kWh, inclusive, charge $0.15 per kWh.
  • For usage above 500 kWh, charge $0.20 per kWh.

Display the total bill amount.

Reflect and Discuss

  • What did you learn from being the Driver?
  • What did you learn from being the Navigator?
  • Discuss any challenges and how you overcame them.
