Flag VDTCanChange (5 pts)

This is where a program stores information which can change.

Flag VDTShouldNotChange (5 pts)
In Python, even though you cannot create a true constant, by convention you can indicate a value should be treated as a constant and not changed by giving it a name with all gb letters.  The flag is under the green box.

Flag VDTTyped (5 pts)
Python is gb typed, meaning the type of a variable can change as the program runs.  For example, you could store "happy" in a variable called state, then you could store 7 in state.  The flag is under the green box.

Flag VDTString (5 pts)

What type will the Python interpreter return for the line below?  The flag is the full line output by the print statement, including all delimiters like angle brackets and single quotes.

print(type("Hello World!"))

Flag VDTReal (5 pts)

What type will it return for the line below?  The flag is the full line output by the print statement, including all delimiters like angle brackets and single quotes.

print(type(3.14))

Flag VDTNotChar (5 pts)

What type will it return for the line below?  The flag is the full line output by the print statement, including all delimiters like angle brackets and single quotes.

print(type('c'))

Flag VDTNumber (5 pts)

What do you use to convert a string literal like "7.29" to a number with a decimal portion, so you can do math with it?  The flag is under the green box.

num = gb("7.29")
