Input

The program below should open a file and read in each number from the file.  It should add each number to a running total as it reads it.  After reading and adding all numbers, it should display the sum of the numbers. 

The code has one or more errors.  See if you can find them.  The program requires an input file called "input".  Create a file called input in the same folder as your main.py file and populate it with several numbers, each listed on separate lines.  

NOTE: You MUST use the name input for the input file.  Do not change it in any way, including adding an extension (e.g., input.txt will NOT work).  If you're using Windows, be sure extensions are visible, so you can ensure there is no extension on this file.

try:
  reader = open "input", "r"
  print("Input values: ", end="")
  for line in reader:
    value = int(line)
    sum += value
    print(value, end=" ")
  print(f"\nSum of values: {sum}")
  input.close
except FileNotFoundError:
  print("Failed to open")

Output

The program below should open a file and write a 10x10 multiplication table to it.  It also should display the table on the screen.  The code has one or more errors.  See if you can find them.

writer = open("output", "w")

MAX = 10
# Determine the width based on the largest number in the table
width = len(str(MAX * MAX)) + 1

for i in range(1, MAX):
  line = ""

  for j in range(1, MAX):
    line += f"{i * j:>{width}}"

  print(line)
  writer.write(line)

writer.close()

Input/Output

This program should open a file for reading and a file for writing.  It first should read a single number from the input stream.  Then it should read that many more values from the input stream (i.e., input file) and output those numbers along with their sum to the output stream (i.e., output file) and to the screen.  Next it should repeat this process of reading a number from the input stream, reading that many more numbers, calculating their sum, and displaying the numbers and sum.  It should terminate when it reads zero from the input stream for the number of values to retrieve or when it encounters the end of the file.  The code has one or more errors.  See if you can find them.  

with open(input, r) as reader, open(output, w) as writer:

  dataRemaining = False
  while dataRemaining:
    line = reader.readline()
    if (not line) or (int(line) == 0):
      dataRemaining = True
    else:
      numVals = int(line)

      writer.write(f"Number of values: {numVals}\nValues: ")
      print(f"Number of values: {numVals}\nValues: ", end="")

      vals = ""
      for _ in range(numVals):
        line = reader.readline()

        if (not line) or (int(line) == 0):
          dataRemaining = False
        else:
          vals += line.strip() + " "
          sum += int(line)

      writer.write(vals)
      print(vals)

      writer.write(f"\nSum: {sum}\n\n")
      print(f"Sum: {sum}\n")
