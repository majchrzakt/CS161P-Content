Adhering to a Specification

One of the goals of this assignment is to see if you can create functions according to a supplied specification. This is important, because sometimes we work with a team of people to create software. Each person agrees to create specific functions which perform specific tasks based on receiving specific inputs and return specific outputs.

For example, one person may create a function named sugarContent which takes the name of a food item and returns a number in grams. Other people on the team may need to call this function to complete their parts of project goals. All they need to know to use the function is its name, the number of arguments it takes, and what it returns. They don't need to know how it performs its task. As long as the person writing the function adheres to its agreed upon specification, the different parts of the software should work when put together.

For the challenges below, although you're not working with a team, to practice the skill of adhering to a specification, you'll need to write your code so it fits the requirements outlined.  For example, if asked to add a function to provided code, you should only add the function and not alter any of the provided code.

Lists

Lists are ordered collections of items that can be of any type.  Each element in a list is accessed by indicating an index, between 0 and n-1 for a list which contains n elements.  Consider the code below.

# Declare and initialize a list of integers
numbers = [10, 20, 30, 40, 50]

# Traverse the list and print each element's value
for i in range(len(numbers)):
    print(f"Element at index {i}: {numbers[i]}")

Get Winner

Consider the code below.  In main it calls getWinner several times to test if it gives the correct output.  This function takes two arguments, where the first one is the user's move, and the second one is the computer's move.  Based on these moves, the function displays a message indicating who won.  The function does not return any values.  

Complete this program by filling in the missing function definition for getWinner.  You should NOT change any other part of the code, including the main function definition.

// Put function definition for getWinner here.
def main():
    # First player (person) wins
    getWinner(1, 0)  # person chose paper, computer chose rock
    getWinner(2, 1)  # person chose scissors, computer chose paper
    getWinner(0, 2)  # person chose rock, computer chose scissors
    # Second player (computer) wins
    getWinner(0, 1)  # person chose rock, computer chose paper
    getWinner(1, 2)  # person chose paper, computer chose scissors
    getWinner(2, 0)  # person chose scissors, computer chose rock
    # Ties
    getWinner(0, 0)  # both chose rock
    getWinner(1, 1)  # both chose paper
    getWinner(2, 2)  # both chose scissors

if __name__ == "__main__":
    main()
