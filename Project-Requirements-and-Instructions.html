Project Required Elements

Your code will be evaluated based on the following elements.

  • Serves intended purpose (entertainment, productivity tool, study aid, etc.)
  • Runs correctly without errors
  • Intuitive interface (include instructions if necessary)
  • Validates user input, if any, and handles data entry errors
  • Creativity
  • Level of difficulty of code
  • Understanding of code as demonstrated in video walkthrough

Graded Project Tasks

The project is worth 50 points, divided among the tasks below.  Part of your grade is determined by the quality feedback you give your peers.  The walkthrough video is required and must include you describing your code.  If no walkthrough video is submitted, the project will earn 0 out of 50 points.

  • Design
    • Plans (5pts) -- Friday week 9
    • Feedback on Peer Plans (5pts) -- Sunday week 9
  • Brief Update
    • GitHub Repo Link (5pts) -- Wednesday week 10
    • Status -- help needed, final plans (5pts) -- Friday week 10
  • Implementation -- Sunday week 10 
    • Demo Video (5pts)
    • Walkthrough Video (15pts) required
    • Both videos must be unlisted on YouTube with links in GitHub README
  • Reviews -- Wednesday week 11 (finals)
    • Review Peer Projects (5pts) -- names emailed Monday week 11 (finals)
    • Rank ALL Projects (5pts) -- available/due Wednesday week 11 (finals)
