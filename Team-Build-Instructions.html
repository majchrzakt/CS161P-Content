Team Build

Most programmers work on a team, which requires careful coordination to ensure all parts of the program work well together.  This activity gives you practice adhering to specifications and introduces you to GitHub, a platform commonly used by programmers to collaborate on projects being managed with the git version control system.

Sign Up and Share GitHub Username

  1. Sign Up:  If you don't already have one, sign up for a GitHub account.  Follow the prompts to set up your username, email, and password. Verify your email address to activate the account. 
  2. Share Username:  Add your username in the spreadsheet below, so I can invite you to collaborate on our Team Build.

Access Team Build Repo on GitHub

  1. Accept Invitation:  Check your email for an invitation to join the Team Build repository (repo).  Click on the link provided in the email to accept the invitation.
  2. Confirm Access:  Go to the Team Build and verify you have access to it.  Can you see the repo?  If you click on a file, do you see a pencil icon showing you can edit it?

Set Up Environment

This assumes you plan to use PyCharm.

  1. If you haven't done so already, install PyCharm
  2. If you haven't done so already, install Git.

Clone Repo

Open PyCharm and do the following to get a copy of the Team Repo on your machine, so you can work on it.

  1. Go to VCS > Get from Version Control....
  2. In the dialog box that pops up, select GitHub on the left.
  3. Click the Log In via GitHub... button.
  4. Click the Authorize in GitHub button on the browser page which opens.
  5. Click the Authorize JetBrains button.
  6. Click the Use passkey button and complete the sign in process.
  7. Enter the repo URL https://github.com/majchrzakt/161P_W25_Team_Build.git
  8. Choose a directory on your machine to clone the project into.
  9. Click the Clone button to create a local copy of the repo.
  10. Click the Trust Project button.

Create Branch for Your Function

Create a new branch where you'll work on your function, either alone or with a partner.

  1. Open Terminal in PyCharm:  Go to View > Tool Windows > Terminal
  2. Check Out Main Branch:  git checkout main  
    This ensures you're on the main branch.
  3. Update Main Branch:  git pull origin main
    This ensures you have the latest changes.
  4. Create and Switch to New Branch:  git checkout -b your-function-name
    Change your-function-name to the name of your function (e.g., git checkout -b validate).
  5. Write and Test Code:  Write and test the code for your function.  If necessary add a temporary function call to your function in main.  Add your name(s) to the function's docstring.

Commit and Push Your Branch

When you're done with your function, you'll push your branch back to the repo where we'll all be able to see your work.  Because you made a branch, it won't automatically try to overwrite the main branch where all our work will come together.

Refer to this image and take the steps indicated below.

  1. Open Commit Tool: Click the commit icon.
  2. Stage Changes: Put a check in the boxes next to the files you changed and want to push to the Team Build
  3. Write Commit Message: Write a meaningful commit message in the active tense (i.e., write Add rather than Added).
  4. Commit Changes: Click the Commit and Push button.
  5. Push Remote Branch to Origin: Click the Push button in the dialog box that appears.

Create Pull Request

Make a pull request to have your branch merged into the main branch.  I'll act as the team lead and manage merging everyone's branches into main.

Refer to this image and take the steps indicated below.

  1. Click the pull request icon.
  2. Click the plus sign.
  3. Add/update the Description.
  4. Click the Create Pull Request button.

Once all branches are merged into main, you can fetch the latest version of the code by choosing Git > Pull, then clicking the Pull button in the dialog box.  Then you can play the fully functional adventure game we created together!
