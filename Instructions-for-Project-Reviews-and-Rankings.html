Review Five Peers

Review your designated peers' code, video demos, and video walkthroughs posted on GitHub.  If they don't have an active link above, look for their GitHub links in the GitHub Link forum.  Their project README should contain links to their videos.  If any links are missing, look for their submissions in the forums under the Project Implementation section.

Rank ALL Projects

Take a quick look at ALL projects created by your peers and rank them (link available on March 18th for one day only).  You can access their posted code and videos, but you may find their demo videos are sufficient.  If there are any peers with no links and no video submissions, which you cannot review, please put them at the lowest ranking.  

Consider the project rubric elements (works correctly, bug free, handles user entry errors), the level of code difficulty, the ease of use (intuitive), the creativity shown in the project, the amount of unique code written by the student, how well they explain their design and code in the videos, and whether or not they give credit to any tutorials/material they referenced.
