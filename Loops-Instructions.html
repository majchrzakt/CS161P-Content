Loop Types

Python has two types of loops: while and for.  If a variable is declared inside a loop, it should only be used inside that loop.  When writing loops, it's important to include a way for the loop to exit.  If it's not possible to exit the loop, it's called an infinite loop, and generates a runtime error from which you can never escape.  For example, the loop below is infinite, because the value of x never changes inside the loop.  Once we get in the loop, we can't get out.

# DON'T DO THIS
x = 6
while x < 7:
    print(x)

while Loops

On the first line of a while loop, we ask a question (i.e., evaluate a condition) to see if the loop should execute.  If the initial answer is False, the while loop never executes.  If the condition is True, we enter the while loop, and it executes at least once.

Consider the while loop below, where the initial answer to the condition is True.  

num = 2
while num <= 10:
    print(num, end=" ")
    num += 2

The while loop executes, because 2 is less than or equal to 10, so it's condition evaluates to True. 

Inside the while loop, note that end=" " in the print statement indicates each line printed should end with a space rather than a new line.  Therefore, all the values get printed on the same line.

A little background information will help us under the last line in the code above.  The computer stores everything as zeros and ones.  If it needs to store the letter 'A', it must covert it into something it can store as a binary number (zeros and ones).  To change 'A' into a number, it looks it up in the ASCII table to find it's position in the table.  Go to the table and scroll down to the ASCII printable characters.  Locate 'A' in the Symbol column.  Notice it's at position 65 (in the DEC column).  Notice 'B' is at position 66, 'C' is at position 67, and so on.  So the position of 'B' is one integer higher than 'A'.  

In the code above, ord returns the ASCII position of the value you give it, and chr returns the character at a given ASCII position.  Try printing each of the following.

ord('A')+1

chr(66)
chr(ord('A')+2)
chr(ord('A')-4)

for Loops

While loops are great when you don't know how many times the loop will need to execute.  When you know exactly how many times a loop must execute, use a for loop instead.  Consider the for loop below.

for i in range(10):
    print(i, end=" ")

If we want a for loop to repeat a set number of times, but we don't need to do anything with the loop variable inside the loop, we can use _ rather than a loop variable name. 

Consider the Turtle code below.

import turtle
wn = turtle.Screen()
t = turtle.Turtle()
for _ in range(10):
    t.forward(50)
    t.right(36)
wn.exitonclick()

Nested Loops

You can put any loop inside any other loop.  Consider the nested for loops below which will display a square made of asterisks (*).

for i in range(1, 6):
    for j in range(1, 4):
        print("*", end=" ")
    print()
