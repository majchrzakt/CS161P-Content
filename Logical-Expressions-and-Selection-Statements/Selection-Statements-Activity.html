Short Circuit Evaluation

Before considering short circuit evaluation, it's important to understand a few things about Python.

  • Anything which evaluates to 0 is considered to be False.
  • Anything which evaluates to something other than 0 is considered to be True.
  • The or operator returns the first True operand or the last operand if none are True.
  • The and operator returns the first False operand or the last operand if all are True.

What this means is that Python is efficient when it evaluates boolean expressions.  As soon as it knows enough, it stops evaluating. 

For example, or requires just one expression to be True to consider the whole condition True.  True or anotherCondition is True, regardless of whether or not anotherCondition is True or False, so it won't waste time evaluating anotherCondition. 

Something similar holds for and.  False and anotherCondition is False, regardless of whether or not anotherCondition is True or False, so again, Python won't waste time evaluating anotherCondition.  Consider the code below.

x = 5
y = 7
if ((x == 3) and (y < 8)):
  print ("something")

The expression x == 3 evaluates to False, because x is 5.  Therefore, Python won't even consider y < 8.  It's not necessary to evaluate, because it already knows it can skip the print.

This holds for non-boolean expressions combined with or as well.  Consider the code below.   What do you think will get printed in each case?  (To learn more, read about Short Circuiting Techniques in Python.)

print(1 and "geeks")
print("geeks" and 1)
print(1 or "geeks")
print("geeks" or 1)

Ternary Statement

You can write a simple if-else statement more succinctly as a ternary statement.  It follows this basic pattern.

Do Something if This is True else Do a Different Thing

As an example, consider this code.

if ((x == 3) and (y < 8)):
  print ("Do Something")
else:
  print ("Do a Different Thing")

You can rewrite the if-else statement above in ternary format on one line as follows.

print ("Do Something") if ((x == 3) and (y < 8)) else print ("Do a Different Thing")

When x is 3 it should print Do Something.  When x is 4 it should print Do a Different Thing.  Try setting x to 3 and then to 4 to test the code and confirm your understanding.
