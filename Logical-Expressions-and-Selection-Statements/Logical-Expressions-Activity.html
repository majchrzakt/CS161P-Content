Operators

There are many kinds of operators in Python, including arithmetic, assignment, comparison, and logical.

What type of operators are <, >, >=, <=, ==, !=, and <>
What type of operators are and, or, and not?
What type is used to store boolean (e.g., True and False) values?

Flag LEGen (5 pts)

Put the answers to the questions above together, separated by pipes to build the flag.  For example, if the answers were a, b, c, d, then enter a|b|c|d to get the flag.  The pipe is above the return/enter key on standard keyboards.

Precedence

Precedence is the order in which operators will be evaluated when there is more than one operator on a line.  W3Schools lists the precedence order for Python operators. 

For each expression below, which operator has the highest precedence?  In other words, without parentheses, which one will execute first?

x + 7 % 8
x and not y
x or y and z

Which operator has the lowest precedence in the expression below? 

x > 7 or y < 8
Flag LEPrec (10 pts)

Put the answers to the four questions above together, separated by pipes, to build the flag.


To not have to worry about precedence in a particular language, you can use parentheses to force the order you desire, and I would argue, to make your code more readable, as follows.

(x > 7) or (y < 8)

Boolean Expressions

Boolean expressions (aka conditionals) evaluate to True or False.  Consider the conditionals below (inside the parentheses of if statements).  Which ones evaluate to True and which to False?  You can try these in an IDE.  If you're not sure why one evaluates a particular way, please ask about it.

if (False or False) ...
if (True or False) ...
if (True and False) ...
if (True and True) ...

int x = 0  
if (x == 0) ...
if (x == 3) ...
Flag LETorF1 (10 pts)

Build the flag by entering T for True or F for False for each of the 6 conditionals above with pipe symbols in between.  For example, the flag could be T|F|F|T|T|F.

HINT: Try printing each of the conditionals (e.g., print(True or False))


Here are some more conditionals for you to try.  See if you can guess whether res is True or False in each case before printing it in an IDE to confirm its value.

p = True
q = False
res = p or not q
res = 8 > 5 and not (2 < 1)
res = True or False and not (True and False)
res = not (6 > 4)
Flag LETorF2 (10 pts)

Build the flag by entering T or F for each occurrence of res above with pipe symbols in between.


Here are some more for you to try.  See if you can guess whether res is True or False in each case before trying it in an IDE to confirm its value.
