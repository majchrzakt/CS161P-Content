Program Flow

When a function is called, control flows to that function.  It's statements are executed.  Then control flows back to the location of the function call.  Consider the program below.  The display_instructions function is called on the second to last line.  Python knows this is a function call rather than a variable, because it's followed by open and close parentheses ( ).

def display_instructions(): # third
  print("This is the game rock, paper, scissors.") # fourth
  print("You are playing against the computer.") # fifth

print("Let's get started!") # first line to execute
display_instructions() # second
print("Thanks for playing!") # sixth

In a future lesson, we'll learn how to import code from one file into another file.  For now, we'll note that when a Python file is imported, all top-level code (i.e., code not inside function definitions) runs automatically.  To prevent this, we can place top-level code inside a main() function, as shown below, and call it only if the file is run directly.

def display_instructions():
  print("This is the game rock, paper, scissors.")
  print("You are playing against the computer.")

def main():
  print("Let's get started!")
  display_instructions()
  print("Thanks for playing!")

if __name__ == "__main__":
  main()
 

Notice that main is called on the very last line, but only if __name__ == "__main__".  When a Python file is run as the main program, Python sets a special built-in variable called __name__ to the string "__main__".  When the file is imported into a different script, __name__ is set to the filename instead.  This check ensures main() runs only when the script is executed, not when it is imported.  Again, we'll learn more about modules in a future lesson.

Parameters

As shown above, a function may have no parameters.  In other words, it may not need anything to be sent to it to complete its tasks.  A function also can require parameters, which it takes in and performs action(s) on.  Consider this code, which defines a function called calcRectangleArea that takes in two values, width and height, and returns area based on these two values.

def calcRectangleArea(width, height):
  return width * height

def main():
  width = 5.0
  height = 10.0
  area = calcRectangleArea(width, height)
  print(f"Area of the rectangle: {area}")

if __name__ == "__main__":
  main()

Scope

Scope is where a variable is known.  It can be local or global.  Consider this code.

globalVar = 10  # global


def demonstrateScope():
  global globalVar
  localVar = 30  # local to demonstrateScope
  print("In demonstrateScope")
  print(f"  localVar: {localVar}")
  print(f"  globalVar: {globalVar}\n")

  localVar += 1
  globalVar += 1


def main():
  localVar = 20  # local to main
  print("In main function before call to demonstrateScope")
  print(f"  localVar: {localVar}")
  print(f"  globalVar: {globalVar}\n")

  demonstrateScope()

  print("In main function after call to demonstrateScope")
  print(f"  localVar: {localVar}")
  print(f"  globalVar: {globalVar}")


if __name__ == "__main__":
  main()

Function Attribute

In Python, functions have attributes which can be accessed using dot notation.  For example, we could define a function as follows.

def calcRectangleArea(width, height):
  return width * height

We could add a string immediately after the function header (i.e., the first line of the function definition), which begins with the keyword def, and ends with a colon : as follows.

def calcRectangleArea(width, height):
  """This function calculates the area of a rectangle"""
  return width * height

This string is called a docstring, and it describes what the function does.  You should include a docstring for every function you define.  Docstrings make code easier to understand and maintain and integrate seamlessly with Python tools and libraries (e.g., doctest, help, Sphinx, PyDoc, pdoc, pdb, Jupyter Notebook) for testing, debugging, and documenting.  A docstring is an attribute of the function and can be printed as follows.

def calcRectangleArea(width, height):
  """This function calculates the area of a rectangle"""
  return width * height

print(calcRectangleArea.__doc__)

The __doc__ attribute is a built in attribute, but we can make our own function attributes, too.  Here's an example where we create an attribute named called for the calcRectangleArea function, and we set it to False.  Note that we can call this attribute anything we want as long as it follows the rules for Python identifiers.

def calcRectangleArea(width, height):
  """This function calculates the area of a rectangle"""
  return width * height

calcRectangleArea.called = False

Say we'd like to know if a function has been called before, so we can do something different on the first call than what we do on all subsequent calls.  Consider the calcRectangleArea function below, which only prints a message the first time it's called.

def calcRectangleArea(width, height):  # function definition
  if not calcRectangleArea.called:
    print("This is the first time I'm being called")
  calcRectangleArea.called = True
  return width * height  # go back to line where called

calcRectangleArea.called = False  # first line to execute
print(calcRectangleArea.called)
print(f"The area is {calcRectangleArea(4, 5)}.")  # function call (jump to definition)
print(calcRectangleArea.called)

NOTE: The first line above to execute is the one where the called attribute is set to False.  Although the function definition is seen earlier, the function doesn't execute until it's called within a print statement a couple lines later.
