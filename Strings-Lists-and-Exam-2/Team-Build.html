Adventure Game Team Build

We're going to build a game together where each member of the class writes one function.  This activity is designed to enhance your understanding of several concepts and to help you develop important skills.

  • Git commands -- manage program versions and individual contributions
  • GitHub -- place to host team project online and merge work together
  • Stubs and driver -- main program runs with stubs;  stubs are developed synchronously by peer programmers, who use small, separate drivers to test them
  • Function specifications -- functions are built as specified, so they work main and other functions

Git

Git is a version control system which allows you to track changes you make to your code.  You can think of it as a backup system, comprised of versions of your code, stored in a repository.  If your code is in a working state, and you make changes to add a new feature and break it, git can help you go back to that prior working state quickly.  I highly encourage you to start using it now for your personal projects.  It's a skill employers expect today.

Do the following to prepare for this activity.

  1. Open the GitBash terminal on a Windows machine or the terminal application on a Mac.  If you don't have GitBash on your system, download and install Git.
  2. Verify git is installed by typing this command on the command line, which should tell you what version you have. 
    git -v

  3. Issue the following two commands to add your name and e-mail address to Git.  Be sure to fill in your name and e-mail where indicated.

    git config --global user.name "Your Name"
git config --global user.email "Your Email"

  4. Set the default branch in Git to main with this command.

    git config --global init.defaultBranch main

GitHub & Function Choice

GitHub hosts git repositories (aka repos) on the Internet.  You can maintain your own repos on it and/or use it as a place to coordinate with a team.  Potential employers will want to see that you have a GitHub account.  The longer you've had it and the more actively you've used it, the better.  Follow the steps below to get starting using GitHub and to collaborate on this class activity.

  1. Register for a free GitHub account.  Make a note of your username.  You'll need it to collaborate on the Adventure Game Team Build project.
  2. Go to the Adventure Game Team Build repo on GitHub.  Look through main.py to review the game loop and the lists of functions which still need to be coded.  Choose ONE function which doesn't already have a name next to it that you'd like to code from the Essential, Reputation, Encounter, and Wealth categories.
  3. Add your name and GitHub username to this page along with the function you'd like to update. I'll add you as a collaborator to the repo and update main, so you're listed as the author.
  4. After receiving an email confirmation that you're a collaborator, in your terminal, change to (go into) the Documents folder with this command.  
    cd Documents
  5. Clone this repo to your machine with the command below, which will make a folder called AdventureGameTeamBuild. 
    git clone https://github.com/majchrzakt/AdventureGameTeamBuild.git
  6. Change to (go into) the AdventureGameTeamBuild folder with this command. 
    cd AdventureGameTeamBuild
  7. After updating your function in the next section, we'll come back to this terminal to push your work to GitHub.

Create Your Function

Go to the Adventure Game Team Build on GitHub and look through its main.py.

  1. Before you begin, open AdventureGameTeamBuild in an IDE and verify that your name appears in main.py, next to the function you chose.
  2. Locate the folder and file which contain the stub for your function, and read through the header describing it at the top of this file.
  3. Open a NEW project in an IDE on your machine.
  4. Create a simple main driver in main.py which calls your function correctly.  For example, if your function requires one integer input and is named myFunc, then you could call it with myFunc(7) in your main driver.  If it returns a value, then you should display what gets returned in your main driver.  Initially, you can write your function definition in your main.py 
    ret_val = myFunc(7)
print(ret_val)
  5. After your function works with your driver in your main.py, replace the stub for your function in AdventureGameTeamBuild with your new function definition, and test it in AdventureGameTeamBuild. 
    ret_val = myFunc(7)
print(ret_val)

Commit and Push

After confirming your function works in AdventureGameTeamBuild, go back to the terminal or reopen it if necessary.

  1. Go into the AdventureGameTeamBuild folder and run this command to see what files you've changed.

    git status
  2. It should display something like what you see below.  In this case, the programmer updated the function definition for merchant_sale in merchant_sale.py, which is in the wealth folder.  Your message will differ based on which function you wrote. 
    modified:   wealth/merchant_sale.py
  3. Alter the commands below appropriately, and run them to stage your work, make a commit, connect to the remote AdventureGameTeamBuild repo on GitHub, set the upstream so your local main corresponds to origin/main on GitHub, pull to your local copy any changes which others have pushed while you've been working, and push your commit to GitHub.  Change wealth/merchant_sale.py to the correct folder and file for your work.  Also, change  Leah to your name.  You can leave off the #s and all text to right of them.  These are just comments. 
    git add wealth/merchant_sale.py   # stage your changes, replace wealth/merchant_sale.py with the file you changed
git commit -m "Add merchant_sale by Leah"   # commit your changes, replace merchant_sale.py and Leah with your information
git remote add origin https://github.com/majchrzakt/AdventureGameTeamBuild.git.   # connect local repo to GitHub repo, call connection origin
git branch --set-upstream-to=origin/main main   # connect GitHub main branch to local main branch
git pull   # pull changes others made to GitHub while you were working and merge them into your local main branch
git push   # push your changes to GitHub

Ambush Function Over the Top

Note that you can get fun icons from your system like the ones used in the code below for the explosion.

  • Mac -- fn key + 'e'
  • Windows -- Windows Key + ';'
# ------------------------------------------------------------------------
#
#  Function: ambush
#
#  Inputs: health (integer)
#  Returns: health (integer)
#
#  Description: Player is ambushed and loses health.
#
#  Author: Samwise Longfellow
#
# ------------------------------------------------------------------------

import random
import time

def ambush(health):
    enemies = [
        "a sneaky goblin",
        "a shadowy bandit",
        "a wild raccoon with glowing eyes",
        "a disgruntled wizard",
        "three unusually aggressive squirrels"
    ]

    enemy = random.choice(enemies)
    damage = random.randint(3, 12)

    print(r"""
       ⚔️   AMBUSH!  ⚔️

           \  |  /
        `.  \ | /  .'
       --  ☠  *  ☠  --
        .'  / | \  `.
           /  |  \
    """)

    time.sleep(1.5)

    print(f"\nWhile walking peacefully, you are attacked by {enemy}!")
    time.sleep(1.5)

    print(f"\nYou struggle to defend yourself...")
    time.sleep(1.5)

    print(f"\nYou take {damage} damage!")
    time.sleep(1)

    health -= damage

    if health <= 0:
        print("\nYou have fallen in battle...")
        health = 0
    elif health < 20:
        print("\nYou are badly wounded! You should find healing soon.")
    else:
        print("\nYou survive the ambush... for now.")

    time.sleep(2)

    return health
