Composition

A list is a collection of elements, which don't all have to be the same.  Below are examples.

numbers = [6, 3, 2]
properties = [17, "tall", [True, 5.2], "red"]


Like characters in strings, we can access elements in lists at specific indices, with the first index being zero.  We also can start at the back of the list and use negative indices to count back from the end.  For the lists above, what value is stored in result by each of the following?  Print result to verify your answers.

result = numbers[0]
result = properties[-3]
result = properties[2]
result = properties[2][0]
Flag LISTComp (5 pts)

Put the answers to the questions above together, separated by pipes to build the flag.  For example, if the answers were a, b, c, d, then enter a|b|c|d to get the flag.  The pipe is above the return/enter key on standard keyboards.


Notice that properties[2][0] accesses the element at index 2 of properties first, in other words properties[2], which is the list [True, 5.2].  Because properties[2] is a list as well, we can access its elements with another index, in this case 0, as in properties[2][0], which is True.  You can think of properties[2][0] as similar to (properties[2])[0] where the part in parentheses is evaluated first.

Mutable

Unlike strings, lists are mutable, meaning we can directly change parts of them.  Consider the ages list again.

ages = [7, 5, 9]
ages[1] = 8
print(ages)

ages = [7, 5, 9]
ages.insert(2, 4)
print(ages)

Optional Parameter

Python will allow you to define optional parameters for a function.  Consider the code below, which has a function called happyFace with an optional parameter called nose.  It requires a file called input with data to be read, and outputs emoticons to a file called output.  You will not see anything display in the console when this program runs.  Check the contents of the output file to see the work it did.

main.py

"""
This program reads emoticon designations from a file
called input, line by line.  For each line, it builds the
corresponding emoticon which is either happy or sad and
has one of four nose types (none, small, big, pointy).
It writes the emoticon to a file called output.

Author: Tina Majchrzak
Date: February 29, 2024
"""
from emoticons import happyFace, writeFace

def main():
  try:
    with open("input", "r") as infile, open("output", "w") as outfile:
      for line in infile:
        parts = line.strip().split()
        #print(f"parts = {parts}")

        if parts and (parts[0] != 'E'):

          face = parts[0]
          #print(f"face = {face}")
          nose = parts[1] if len(parts) > 1 else None
          #print(f"nose = {nose}")

          outStr = ""
          if face == 'H':
            outStr = happyFace() if nose is None else happyFace(nose)
            writeFace(outStr, outfile)
          else:
            print(f"Invalid face read: {face}")
          #print()

  except Exception as e:
    print(f"Failed to open or process files: {e}")

if __name__ == "__main__":
  main()
 
 

emoticons.py

def happyFace(noseType=None):
  """
  Function to create a simple happy face emoticon.

  Parameters:
  - noseType (str, optional): The type of nose for the emoticon.
    Options are 'B', 'P', 'S', or None.

  Returns:
  - str: A string representing a happy face emoticon.
  """
  if noseType == 'B':  # big nose
    face = ":o)"
  elif noseType == 'P':  # pointy nose
    face = ":^)"
  elif noseType == 'S':  # small nose
    face = ":-)"
  else:  # no nose
    face = ":)"
  return face

def writeFace(outStr, outfile):
  """
  Takes a string, outStr, to write to a file, outfile.

  Parameters:
  - outStr: The string to write to the file.
  - outfile: The file object to write to.
  """
  outfile.write(outStr + "\n")

Notice the inclusion of a header comment at the top of main.py describing what the program does, the author, and the date.  There also is a docstring comment as the first line for each function describing what it does, what parameters it takes, and what it returns.  It is a best practice to include these comments in your work.

Notice also in main.py that we can call two methods using dot notation as in the following.

parts = line.strip().split()

This takes the line read in from the file, which is a string, calls strip on it to remove white space at the beginning and end of it, including the carriage return, and then calls split on that to create a list containing each character separately.
