Immutable

Strings are immutable, meaning we can't change them directly.  What happens when you try to do this?

newString[0] = "b"  # BAD - Don't do this!
Flag STRImmut (10 pts)

Your IDE should generate an error message.  What does it say is not supported?  Hint: the answer is two words.


Instead of trying to change newString directly, we can do the following.

newString = "b" + newString[1:]


The + on the right side of the = sign evaluates first and creates a new string on the right.  Then the = sign evaluates and newString gets set to point to the new string created on the right.  Essentially, we lose track of the string, "peal", to which newString pointed before this line executed, and now it points to the freshly created "beal". 

To understand what's happening at a deeper level, it's helpful to realize that "peal" and "beal" are stored at two different starting memory locations in the computer.  The value of newString initially holds the starting memory location of "peal."  After executing the command above, it holds the starting memory location of "beal."  So we haven't changed "peal."  It's immutable (unchangeable).  Instead, we've created a whole new string called "beal."

Traversing

Sometimes we want to traverse a string, in other words look at each character in a string one by one, and make a decision about it.  For example, we may want to count the number of a's and e's in a phrase.

phrase = "The quick brown fox jumps over the lazy dog"
countE = 0

for c in range(len(phrase)):
  if (phrase[c].lower() == 'a') or (phrase[c].lower() == 'e'):
    countE += 1
print(f"The number of a's and e's in the phrase is {countE}.")
 
 

Alternatively, we could traverse the string and accomplish the same task by writing the code below.  It uses a more concise syntax for the for loop and incorporates a list containing the characters 'a' and 'e' to which each character, c, is compared, one by one.

for c in phrase:
  if c in ['e', 'a']:
    countE += 1
print(f"The number of a's and e's in the phrase is {countE}.")
